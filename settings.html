Printer Settings

Paper size, text scale and the ESC/POS bill layout for this printer. Tax Invoice / UAE layouts and Full Arabic are set in the web dashboard (Settings → Store → Bill Printing).

Printer type
Print mode
Bill layout (ESC/POS)
Built-in layout
Every line of the bill is editable. The layout is saved to your Menuthere account, so it follows you to any PC and the Menuthere team can adjust it for you. Applies to ESC/POS prints.
Bill printer
Tick every printer the bill should come out of. Nothing ticked = Windows default printer.
KOT printer
Tick more than one to print the same document in two places — e.g. the counter printer takes the bill and the KOT, while the kitchen printer takes only the KOT. Use x for copies: set the kitchen printer to 2 to get two KOTs from it.
Width (dots)
Printhead width. 58 mm ≈ 384, 80 mm ≈ 576. Increase until the test bar just fills the paper.
Scale (text size)
Bigger = larger text (long bilingual lines wrap sooner).
Tip: open this anytime with Ctrl+Shift+P or the tray icon.
